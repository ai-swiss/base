# Où lire la spécification BASE

La spécification d'ingénierie courante de BASE vit dans
[`specs/current/`](../../specs/current/README.md). Elle décrit le broker, la CLI, le MCP, les
schémas et leurs invariants, reliés au code et aux tests. En cas de divergence avec un autre
document, `specs/current/` fait foi.
