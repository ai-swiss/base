# Where to read the BASE specification

The current BASE engineering specification lives in
[`specs/current/`](../../../specs/current/README.md). It describes the broker, CLI, MCP, schemas,
and their invariants, tied to code and tests. If another document diverges from it,
`specs/current/` is authoritative.
