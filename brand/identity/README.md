# Identité visuelle de BASE

Ce dossier conserve les six fichiers sources validés de l'identité visuelle:

- `base-symbol-on-black.png`: symbole seul;
- `base-wordmark-horizontal-on-black.png`: symbole rouge et mot-symbole horizontal;
- `base-wordmark-monochrome-on-black.png`: version horizontale monochrome;
- `base-lockup-vertical-on-black.png`: composition verticale;
- `base-wordmark-reversed-on-anthracite.png`: version horizontale claire sur fond anthracite;
- `base-logo-reference-sheet.png`: planche de référence des compositions et couleurs.

La version horizontale inversée est la déclinaison principale pour les en-têtes numériques. Sa copie
publique, utilisée par les README, se trouve dans `docs/public/assets/base-logo.png`.
